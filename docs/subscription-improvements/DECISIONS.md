# Решения по доработкам Xkeen-UI

## Согласовано пользователем

- Область подписок: только Xray.
- Целевая установка: Xkeen-UI 3.0.2, Keenetic Ultra, Keenetic OS 5.1.8.
- Отдельный cron каждой подписки, пять полей, часовой пояс роутера; режим интервала сохраняется.
- Регулярные выражения нужны в сохраняемом поле «Фильтр по имени». ws — пример, отдельное правило под него не требуется.
- Разрешён осмотр домашнего роутера. Продуктивные настройки не менялись.
- Перед созданием PR пользователь должен получить и согласовать описание со всеми используемыми скриншотами. PR до согласования не создавать.

## Технические решения

- Единый движок фильтров — Python re: валидация, живой предпросмотр, сохранение и обновление используют его синтаксис. Это не обещание совместимости с каждым другим движком regex. Выражения вводятся без JavaScript-разделителей /…/.
- Поддерживаются группы и альтернативы, классы, якоря, lookahead/lookbehind, именованные группы и обратные ссылки в пределах Python re. Регистр по умолчанию игнорируется, встроенные флаги доступны.
- Cron поддерживает числа, *, списки, диапазоны и шаги. День недели 0/7 — воскресенье. Если ограничены и день месяца, и день недели, они объединяются по правилу OR стандартного cron.
- После простоя выполняется один просроченный запуск. После завершения cron рассчитывается от текущего времени, а не от времени начала скачивания. Ручное обновление не сдвигает календарные точки.
- При ошибке сохраняется ограниченный повтор; ближайшая календарная точка не пропускается из-за более позднего повтора. При переходе времени отсутствующие местные минуты пропускаются, повторяющаяся минута может выполняться дважды. DST-тесты доступны на POSIX и пропускаются на Windows.
- Планировщик проверяет наступившие сроки периодически: cron определяет календарную точку с точностью до минуты, но не гарантирует запуск ровно в нулевую секунду при загрузке устройства.
- Кеш скачивания существует только в пределах одной пачки. Ключ: URL и нормализованный профиль запроса. Локальные фильтры каждой подписки независимы. Ошибка общей загрузки тоже переиспользуется внутри пачки.
- Перезапуск учитывает итоговую конфигурацию; временная перезапись с восстановлением прежнего содержимого сама по себе не требует рестарта. JSON сравнивается без учёта форматирования и комментариев, с сохранением порядка массивов.
- Компактный ответ списка включается отдельным заголовком; обычный API остаётся совместимым. Внутренние last_generated_outbounds остаются в состоянии сервера, но не передаются интерфейсу при загрузке списка.
- Изображения для PR получены на локальных обезличенных стендах: исходный commit тега v3.0.2 и изменённая ветка, одинаковые данные и размеры окна. Скриншоты домашних подписок не публикуются.

## Уточнение компоновки от менеджера

Выбор режима и активное поле интервала/cron находятся рядом. При выборе cron весь блок интервала скрывается, при выборе интервала скрывается поле cron. На ширине 390 px проверено расположение выбора режима и поля cron в одной строке.
